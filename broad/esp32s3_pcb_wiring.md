# ESP32-S3 仪表板打板接线说明

## 1. 屏幕接线不是完全通用

只有屏幕分辨率、接口类型和电平都一致时，软线端子才能复用。建议把主板屏幕接口做成“按总线分类”的端子，不要只按 LCD 排线顺序定义。

| 屏幕类型 | 是否可直接复用当前 I80 接线 | 需要的信号 |
|---|---|---|
| ST7796U/ILI9488，16-bit 8080/I80 | 可以，前提是驱动和分辨率匹配 | D0-D15、WR、RD、DC、CS、RESET、背光、电源、GND |
| ST7789/ILI9341，SPI | 不可以 | SCLK、MOSI、MISO（可选）、DC、CS、RESET、背光、电源、GND |
| RGB565/非 SPI 并口屏 | 不可以 | RGB 数据线、PCLK、HSYNC、VSYNC、DE、RESET、背光 |
| MIPI-DSI 屏 | 不可以 | DSI 差分对、时钟差分对、专用电源和复位，不能直接接 ESP32-S3 |
| GT1151/GT911/FT5x06 触摸 | 只要都是 I2C 才可能复用 | SDA、SCL、INT、RESET、电源、GND；地址可能不同 |
| XPT2046 电阻触摸 | 不可以 | SPI、CS、IRQ，和 I2C 触摸不同 |

当前工程的 S3 板级配置是 16-bit I80 + GT1151 I2C。换成 SPI 屏需要同时更换固件 profile 和端子定义，不能只替换屏幕排线。

## 2. 推荐的软线端子分组

不要把所有信号做成一个超宽插座，建议分组，便于换屏和维修。

### J1：电源输入

| 端子 | 信号 |
|---|---|
| 1 | `VIN+`，接受 5V 或 12V，具体范围由电源级决定 |
| 2 | `GND` |
| 3 | `IGN/EN`，可选，接车辆点火控制 |

### J2：I80 LCD

`3V3、GND、D0-D15、WR、RD、DC、CS、RESET、BL_EN`

当前固件 GPIO 分配为：

```text
D0..D15 = 13,12,11,10,9,46,3,8,18,17,16,15,7,6,5,4
RD=14  WR=45  DC=38  CS=39
```

### J3：SPI LCD（预留）

`3V3、GND、SCLK、MOSI、MISO、DC、CS、RESET、BL_EN`

SPI 屏和 I80 屏建议使用不同插座键位，避免误插。

### J4：I2C 触摸

`3V3、GND、SCL、SDA、INT、RESET`

当前 GT1151：`SCL=GPIO40`、`SDA=GPIO41`、`INT=GPIO42`。当前配置文件中的 `I2C_ADDRESS=20` 按十进制解析，即 GT1151 地址为 `0x14`；XL9555 地址为 `0x20`。换触摸芯片前仍必须核对地址。

### J5：GPS

`3V3、GND、GPS_TX、GPS_RX、PPS`

建议预留：

```text
GPS_TX -> ESP32-S3 GPIO37（模块 TX 接 MCU RX）
GPS_RX -> ESP32-S3 GPIO48（MCU TX 接模块 RX）
PPS    -> ESP32-S3 GPIO47
```

GPS UART 必须是 3.3V 电平；5V UART 需要电平转换。

## 3. 5V 和 12V 输入能否共用 DC-DC

取决于 DC-DC 拓扑：

| 电源模块 | 5V 输入 | 12V 输入 | 结论 |
|---|---:|---:|---|
| 普通降压 Buck，输出 5V | 不适合，输入没有压差 | 可以 | 不能同时覆盖 5V/12V |
| 普通升压 Boost，输出 5V | 可以但不能承受高于输出的输入 | 不可以 | 不适合车辆输入 |
| 升降压 Buck-Boost，输出 5V | 可以 | 可以 | 推荐 |
| 5V/12V 自动切换或宽压模块 | 视规格 | 视规格 | 必须看输入范围和输出压差 |

建议选择输入范围至少 `4.5~36V`、稳定输出 `5V/3A` 的同步四开关 Buck-Boost。若只使用普通 Buck，最低输入电压应留出压差，5V 输入时通常无法稳定输出 5V。

车辆 12V 不是理想 12V：应在输入端加入保险丝、反接保护、TVS、输入滤波和欠压/过压保护。不要把 12V 直接接 ESP32-S3、GT1151、XL9555 或 LCD 的 3.3V 引脚。

## 4. 电源分配建议

```text
VIN 5/12V
  -> 保险丝
  -> 反接保护
  -> TVS + 输入滤波
  -> 4.5~36V Buck-Boost，输出 5V
       -> LCD 背光/需要 5V 的外围
       -> 3.3V LDO/DC-DC
            -> ESP32-S3
            -> GT1151
            -> XL9555
            -> GPS
```

如果所选 LCD 背光只能接 5V，背光电流必须经过独立 MOSFET 或屏幕自带驱动，不能让 XL9555 端口直接承受背光电流。XL9555 只输出背光控制信号。

## 5. 打板前必须确认

1. 屏幕接口是 I80、SPI、RGB 还是 MIPI。
2. LCD/触摸的逻辑电压和背光电压、电流。
3. 触摸 I2C 地址是否与 XL9555 冲突。
4. GPS 模块 TX/RX/PPS 是否为 3.3V。
5. DC-DC 的最低输入电压、最高输入电压、启动电压和瞬态耐压。
6. ESP32-S3 模组实际引出的 GPIO；GPIO3、45、46 属于当前配置中的高风险引脚，不能随意改作外部强上拉/下拉。
