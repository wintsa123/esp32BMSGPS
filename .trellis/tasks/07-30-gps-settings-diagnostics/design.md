# GPS 设置诊断状态设计

## Data Flow

`GSA` 解析定位维度、有效卫星数和 HDOP；`GSV` 解析可见卫星数与每颗星的 C/N0，
计算当前语句的平均 SNR。GPS 组件将两项新值与现有卫星数据一起发布到运行时快照，
LVGL 设置页使用快照直接生成诊断文案。

## Display Rules

- 定位模式：无有效卫星信息时“无效”；否则按 GSA 的 2D / 3D 值显示。
- 卫星系统：从校验通过的 GSV 报文的 talker 和卫星 PRN 汇总实时星座；只根据观测到的
  GPS、北斗和 GLONASS 组合显示，避免把模块能力误报为当前三模状态。
- 卫星：显示 `可见 / 有效`，并标明“最多 32，至少 5 颗稳定测速”。
- 平均 SNR：显示 0--45 dBHz 和“越大越好”；小于 10 显示“信号差，测速易漂移”。
- HDOP：小于 1.5 显示“优秀”；大于 4 显示“不建议测加速成绩”。

## Boundaries

- 不向 336H 写入任何 UART 配置命令。
- 不新增 GPIO、天线检测或接收机配置切换。
- NMEA 数据失效时保留 `--`，不把旧读数当成当前状态。
- GPS 诊断行不路由操作事件，使用禁用态灰显。
