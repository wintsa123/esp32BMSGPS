# 轮播黑场卡片转场

## Goal

将轮播的黑场标题占位页升级为卡片式转场：切页开始时黑卡满屏，随即收缩为
带边框的黑色卡片并跟手横移；松手后目标或原页卡片放大为满屏，再恢复完整页面。
拖动阶段只绘制卡片和标题，减少仪表与 BMS 页面重绘。

## Confirmed Facts

- 生产固件和 SDL 模拟器共用
  `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c`；本次 UI 逻辑无需在模拟器
  复制一套实现。
- 既有 `page_transition_*()` 已在 `s_ui.pages` 内创建 BMS、仪表、投屏三张黑色
  占位页。它们既是 `LV_OBJ_FLAG_SNAPPABLE` 的全宽页面，也是保证隐藏真实页后
  轮播边界不收缩的必要内容。
- `page_scroll_event_cb()` 在 `LV_EVENT_SCROLL_BEGIN` 显示占位页，在最终
  `LV_EVENT_SCROLL_END` 立即恢复真实页；`finish_page_scroll_state()` 是所有中断
  和重建路径的兜底恢复点。
- 无头模拟器的原生手势冒烟会直接调用黑场转场检查；交互式 SDL 窗口则以 LVGL
  指针滚动运行。

## Requirements

- R1: 轮播开始时，真实页必须先被不透明黑场占位层遮住；当前黑卡以满屏尺寸开始，
  随后在 100 ms 内缩至四周 8 px 边距、8 px 圆角、1 px 深灰边框的卡片。
- R2: 跟手期间，满宽、可吸附的占位页继续负责横向滚动；缩小的黑卡及其居中标题
  随所属占位页移动。不得使用阴影、模糊、不透明度动画、截图缓存或额外帧缓冲。
- R3: 最终 `LV_EVENT_SCROLL_END` 不得直接显示真实页：当前目标卡片必须在 100 ms
  内放大为满屏，然后才恢复目标真实页并应用延迟快照。未达到既有阈值时同样放大
  原页卡片后恢复原页。
- R4: 保持既有页面顺序、手势阈值、原生手势、程序化 `set_page` 语义、轮播滚动边界
  和设置/锁屏/启动动画互斥条件不变。
- R5: 所有提前结束、页面重建、设置切换或动画中断路径必须停止卡片动画、恢复真实页，
  且不能留下黑卡、隐藏页面或延迟快照。
- R6: 交付生产固件和模拟器共用实现；完成后构建但不烧录，并重新启动交互式模拟器。

## Acceptance Criteria

- [x] AC1: 横向拖动起始阶段先显示全屏黑页，再收缩成带框黑卡；卡片和 BMS、仪表、
  投屏标题按手势跟随移动。
- [x] AC2: 成功切页与取消切页都会先将对应黑卡放大为满屏，随后恢复正确的完整页面；
  不出现闪白、空白页或卡片残留。
- [x] AC3: 原生手势、鼠标指针轮播和 `esp_bms_lvgl_ui_set_page(..., true)` 的页面
  目标、阈值、边界和快照延迟语义保持不变。
- [x] AC4: 模拟器自动检查卡片的收缩、放大、标题、滚动边界和恢复状态；横竖屏
  `--headless` 均通过，且交互式模拟器被重新启动。
- [x] AC5: 目标 ESP-IDF 构建、`git diff --check` 和 GitNexus `detect-changes` 通过；
  不执行烧录。
