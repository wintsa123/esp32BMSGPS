# 执行计划

1. 对黑场创建、显示、隐藏、滚动回调和收尾函数执行 GitNexus upstream impact，确认
   风险范围后再编辑。
2. 在 UI 状态中保存三张卡片对象及收尾所需的动画状态；实现统一的重置、缩卡、放大
   和取消动画辅助函数。
3. 将黑场占位页改为透明满宽包装页加黑色子卡片，保持页面吸附范围不变。
4. 在滚动开始收卡，在最终滚动结束放大稳定槽位卡片；放大完成后才恢复真实页并刷新
   延迟快照。所有中断路径立即取消并恢复。
5. 扩展生产 UI 的模拟器冒烟，断言满屏/缩卡/放大几何、标题、滚动边界与真实页恢复。
6. 运行横竖屏无头模拟器、目标 ESP-IDF 构建、差异检查和 GitNexus 变更映射；不烧录。
7. 更新 LVGL 桌面模拟器及轮播契约，提交、归档任务，并重新启动交互式模拟器。

## Risk Gates

- `page_transition_hide()`、`page_transition_show()`、`page_transition_page_create()`、
  `finish_page_scroll_state()`、`page_scroll_event_cb()` 和 `create_screen()` 都必须在
  编辑前完成影响分析；若出现 HIGH 或 CRITICAL，先向用户报告并确认边界。
- 每个动画对象只允许在单一收尾回调中恢复真实页；任何路径都不得既刷新快照又留下
  占位页可见。
