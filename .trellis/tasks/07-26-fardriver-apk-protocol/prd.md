# 远驱 APK 蓝牙协议复核

## Goal

从仓库根目录的 `far.apk` 提取 FarDriver 蓝牙协议证据，核对并修正本机
控制器 BLE 实现对服务、特征、命令、校验和遥测字段的解释，使轮胎规格、
转速、温度及现有 dashboard 所依赖的其它遥测值来自真实协议而非推测。

## Confirmed Facts

- `far.apk` 是 Android APK，包含 `classes*.dex` 和原生协议库
  `lib/arm64-v8a/libfd_protocol.so`。
- APK 的 FarDriver 连接层使用 Nordic UART：服务 UUID
  `6e400001-b5a3-f393-e0a9-e50e24dcca9e`，通知特征为 `...0003...`，
  写入特征为 `...0002...`；本机仍使用 `FFE0/FFEC`。
- APK 将紧凑遥测帧定义为 16 字节、`0xAA` 起始，`frame[1]` 无高位，
  `frame[14:16]` 为 `frame[0:14]` 的 16 位累加和（大端）。带高位的
  扩展帧使用 `0x3C/0x7F` 初值 CRC；现有实现错误地对所有帧使用 CRC。
- APK 对扩展帧以 `frame[1] & 0x7F` 查表，表项对应本机已有的
  `FLASH_READ_ADDR`；现有实现依赖索引数值范围，会把部分扩展帧错当紧凑帧。
- APK 写入的读取请求是 5 字节 `address,address,0x80,crc_hi,crc_lo`，
  并轮询 13 个实时块和 27 个配置块；现有实现发送单个未经 APK 验证的
  8 字节 gather 命令。
- APK 将紧凑帧的原始电角速度按极对数换算为机械 RPM，并从实时电压和
  电流计算功率；现有实现使用 `raw/4` 和推测的 d/q 电流偏移。
- 现有父任务已实现基于 `D2/D3/D4` 参数块的轮胎规格、传动比和车速派生，
  但其任务记录没有 APK 反编译或原生库证据。
- 本仓库当前有未提交的控制器 BLE、runtime、设置 UI 等改动；本任务必须
  保留它们，只修改经 APK 证据证实需要修正的代码。
- 本任务只读分析 APK；不对 APK 重签、重打包、发布或绕过其访问控制。

## Requirements

- 从 APK 的 DEX 和 `libfd_protocol.so` 提取可复现的服务/特征 UUID、帧封装、
  命令码、长度、字节序、校验与字段缩放证据；无法静态确认的内容明确标记。
- 覆盖至少轮胎规格/传动比、转速、控制器温度、电机温度及本地 dashboard
  已消费的其它 FarDriver 遥测字段。
- 将 APK 结论与 `components/esp_fardriver_protocol`、控制器 BLE 收发流程和
  runtime snapshot 逐项比对；只修正存在明确差异的实现。
- 为每项解析修正添加最小的 host 自检，使用来自 APK 的帧或命令样本锁定
  字段偏移、字节序、缩放和 CRC 行为。
- 只读取数据：仅允许订阅通知和向 BLE 写特征发送 APK 定义的只读寄存器
  请求；禁止发送任何写寄存器、调参、远程驱动、密码或控制命令。

## Acceptance Criteria

- [ ] 协议证据写入任务文档，包含来源文件、符号/常量位置及每项结论的
  确定性等级。
- [ ] 服务/特征 UUID、订阅、读写命令及帧校验与 APK 一致，或对无法静态
  确认的差异明确记录为硬件待验项。
- [ ] 轮胎规格、传动比、转速、控制器温度和电机温度的解析均有可运行的
  host 自检覆盖；已证实的差异已修正。
- [ ] 本机固件不因不完整帧、校验失败或异常缩放覆盖最后有效遥测状态。
- [ ] 固件只发送 APK 格式的只读请求，代码与自检均不包含 FarDriver
  写寄存器或控制帧。
- [ ] 受影响的 host 自检、`git diff --check`、目标 ESP-IDF build 和
  GitNexus 变更检测通过。

## Out of Scope

- APK 重打包、签名、运行时注入或访问控制绕过。
- 远驱控制器参数写入、调参、故障码诊断或新的 Web UI。
- 没有 APK 证据支撑的广泛重构。

## Decisions

- 用户已确认直接按 APK 静态证据修正；本任务不进行实机连接、抓包、刷写
  或验证。硬件兼容性留给后续独立验证。
