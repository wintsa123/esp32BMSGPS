# 修复 S3 配置器退出与显示方向颜色

## Goal

修复 ESP32-S3 Dash 开发板配置器在 UI 选择页按回车后异常退出的问题，并让该板的静态仪表画面与已正确的轮播画面保持相同方向和正常颜色。

## Confirmed Facts

- 在 `start` 脚本中选择 `esp32s3 Dash` 开发板、勾选任一 UI 后，在 UI 选择页按回车会直接退出脚本。
- 该退出已在伪终端复现：离开仪表页后 `configure_audio_profile` 在未选择 audio 时以失败状态返回，`start.sh` 的 `set -e` 因而终止脚本。
- 已烧录的 S3 固件可以亮屏；轮播图方向正确，但仪表静态画面方向错误且颜色反色。
- 实际 S3 Dash 使用 3.5 英寸、`480x320` 的横屏显示；当前目录的 `320x480` 物理坐标配合横屏旋转会得到该逻辑分辨率，不需要变更页面尺寸。
- 运行时启动入口会用持久化的显示方向覆盖板级默认；修复面板默认方向时，必须让首次启动和旧版 NVS 配置迁移到该默认值，同时保留用户之后的方向选择。
- 修复范围仅限启动配置流程和 ESP32-S3 Dash 显示配置，不改变其他板型或 UI 主题的行为。

## Requirements

- R1: UI 选择页的回车必须进入下一配置步骤或完成当前配置，不能无提示退出。
- R2: ESP32-S3 Dash 的静态仪表画面必须与其轮播图使用一致的显示方向。
- R3: ESP32-S3 Dash 的显示颜色必须正常，不能反色。
- R4: ESP32-S3 Dash 的显示分辨率、方向和像素格式必须与实际 3.5 英寸 `480x320` 面板匹配，静态仪表铺满物理屏幕。
- R5: 保持现有可裁剪构建、其他目标板和已正确轮播效果不回归。

## Acceptance Criteria

- [ ] AC1: 选择 ESP32-S3 Dash、切换至少一个 UI 后按回车，脚本继续到下一步或明确完成提示，退出码为 0。
- [ ] AC2: S3 Dash 的静态仪表和轮播画面在物理屏幕上方向一致、颜色正常。
- [ ] AC3: S3 Dash 的静态仪表铺满 3.5 英寸 `480x320` 物理显示区域，不留黑边或错位。
- [ ] AC4: 相关 ESP32-S3 构建通过项目既有构建流程。
- [ ] AC5: 所有与此任务有关的自动化检查通过，且改动未超出预期调用链。

## Out Of Scope

- 不修改其他仪表主题的视觉设计。
- 不变更屏幕硬件接线、分区或 OTA 策略。
