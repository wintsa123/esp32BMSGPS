# 微调轮播黑卡尺寸与转场时长

## Goal

让轮播拖拽中的黑色标题卡片更明显地缩小，并让进入和退出卡片状态的过渡更从容，保持上一轮已实现的轻量黑卡轮播和真实页面还原行为。

## Confirmed Facts

- `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 将黑卡的内缩和动画时长集中在
  `PAGE_TRANSITION_CARD_MARGIN` 与 `PAGE_TRANSITION_CARD_ANIM_MS`。
- 现有模拟器冒烟检查使用同一组常量验证缩卡和还原，因此调参后会自动覆盖新几何和时长。
- 用户要求同时验证正式固件和横竖屏模拟器，完成后重启交互式模拟器；本次不烧录。

## Requirements

- 将黑卡内缩由 8px 调整为 16px，使拖拽中的卡片更小。
- 将黑卡缩小和放大的动画时长由 100ms 调整为 160ms。
- 同步更新轮播转场契约中的尺寸与时长，避免规范与实现漂移。
- 保持占位页滚动范围、跟指标题移动、松手扩展为真实页面以及所有既有清理路径不变。

## Acceptance Criteria

- [x] 横向和纵向无头模拟器的轮播转场冒烟检查通过。
- [x] 正式固件构建成功，未执行烧录。
- [x] 交互式模拟器在本次变更后重启成功。
- [ ] 本任务仅提交黑卡调参、相应契约和任务记录，不包含工作区其他改动。

## Out Of Scope

- 不改变轮播拖拽阈值、页面标题、卡片配色、圆角或真实页面的内容与布局。
- 不烧录或干预任何正在使用硬件串口的任务。
