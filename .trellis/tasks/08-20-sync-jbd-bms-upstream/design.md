# Design

## Boundary

改动限制在 `protocols/jbd/esp_bms_jbd_protocol.c` 和对应自测。现有 BLE 服务/特征已与上游默认配置一致，不修改连接层。

## Frame Assembly

- 普通响应以 `0xDD` 开始，只有至少四字节后才读取长度；总长为 `7 + data_len`，验证状态、补码校验和 `0x77`。
- 认证响应必须以 `FF AA` 开始，总长为 `5 + data_len`，验证认证校验后整体丢弃；不执行认证状态转换。
- 无效帧每次至少丢弃一个字节并重新同步，超长声明立即丢弃帧头，不能永久等待不可能到达的数据。
- 一次通知含多个帧时持续消费，返回第一个有效 `0x03` 遥测，同时保持剩余数据可供下次处理。

## Read Compatibility

保持 `0x03` 基础遥测和 `0x04` 单体帧消费行为。`0x05` 硬件版本与 `0xAA` 错误计数通过完整帧校验后安全消费，不投影到公共遥测结构。

## Security

不内置上游根密码，不处理用户密码，不发认证或写命令。以后若需要控制能力，必须单独设计凭据存储和用户确认边界。
