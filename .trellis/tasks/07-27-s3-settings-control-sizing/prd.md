# 调整 S3 设置页面控件尺寸

## Goal

在 ESP32-S3 Dash 的 480x320（及旋转后的 320x480）逻辑分辨率下，提高设置页的可读性和触控尺寸，同时保留旧 320x240 / 240x320 布局。

## Confirmed Facts

- S3 Dash 的 ST7796U 面板逻辑分辨率为 480x320；用户切换旋转后可为 320x480。
- 设置主列表由 `create_screen` 创建，详情行复用 `settings_detail_row`，数字选择复用 `settings_controller_roller`。
- 设置中文字体当前最高为 16px；为了让 S3 上的中文标题实际变大，需要生成 18px 的同字形集，并只在 S3 与主机模拟器中链接。
- 右侧 `>` 为列表/选择行的进入图标；快捷面板的编辑图标由 `quick_edit_set_pressed` 重新居中。

## Requirements

- R1: 仅在 S3 级别的大分辨率布局下增大设置主列表和详情列表的行高、垂直留白与可读字体；S3 使用 18px 标题、16px 副标题，旧分辨率保持原尺寸和字库。
- R2: 设置详情顶部导航栏在大分辨率下增高，标题和操作图标保持居中且不遮挡滚动内容。
- R3: 列表/选择行右侧的进入图标略缩小；快捷面板编辑图标略放大，按下时仍正确居中。
- R4: 预设里程、轮胎规格和传动比的数字滚轮在大分辨率下增大，选中状态和确认交互不变。
- R5: 不改变设置路由、事件回调、持久化数据、旧 ESP32 布局或面板驱动行为。

## Acceptance Criteria

- [ ] AC1: 在 480x320 和 320x480 的设置页中，主列表、详情行和顶部导航栏都比旧基线更高，文本未裁切或重叠。
- [ ] AC2: 大分辨率数字滚轮显示更大字体和更大的可触区域，确认动作仍提交原有数值。
- [ ] AC3: 主列表和详情列表的进入图标缩小，快捷编辑图标增大且按下/松开时保持居中。
- [ ] AC4: 320x240 和 240x320 的既有设置尺寸不变。
- [ ] AC5: S3 模拟器检查及目标构建通过，变更只覆盖预期 UI 符号和执行流。

## Out Of Scope

- 不新增设置页功能、配置项或非 S3 的字体资源。
- 不修改显示方向、触摸映射、颜色处理或其他仪表页面。
