# 仪表设置归位与 GPS 图标裁剪

## Goal

将速度单位、速度来源和仪表样式从 GPS/控制器设置中归位到独立的“仪表”一级设置，并保证宝马 S1000RR 仪表在未编译 GPS 时不绘制任何 GPS 卫星状态图标。

## Confirmed Facts

- GPS 详情当前包含模块状态、定位、时间、速度单位，并在 GPS+控制器构建中包含速度来源。
- 控制器详情当前标题为“速度仪表”，包含仪表 UI、控制器连接、速度单位、轮胎规格和传动比。
- 速度单位和速度来源已有动作协议、快照字段和选择器，不需要修改 NVS 或运行时语义。
- 宝马 S1000RR 仪表由 `speed_dashboard_draw_event_cb()` 绘制卫星图标；当前调用未受 `ESP_BMS_FEATURE_GPS` 保护，因此无 GPS 构建仍显示未定位图标。
- GPS 卫星数量、信噪比和星座信息尚未进入运行时快照；当前 GPS 解析只消费 RMC，GSA/GSV 被忽略，超过 96 字节的长句会按既有边界整体丢弃。

## Requirements

- 设置根页在 `ESP_BMS_FEATURE_GPS || ESP_BMS_FEATURE_CONTROLLER` 时显示独立一级“仪表”入口。
- “仪表”详情承载仪表 UI 和速度单位；速度来源仅在 GPS 与控制器同时编译时显示。
- GPS 详情只保留 GPS 自身状态：模块状态、定位状态和本地时间，不再显示速度单位或速度来源。
- GPS 接收链路解析校验和有效的 GSA/GSV，发布可见卫星数、参与定位卫星数、最强 `C/N0` 和 `2D/3D` 定位维度；损坏或不完整语句不得覆盖最后一次有效数据。
- 搜星信息必须有有效性和陈旧超时：模块离线或卫星数据超时后显示 `--`，不得永久保留旧卫星数。
- GPS 详情增加搜星信息展示，并在卫星数量或信号变化时仅刷新当前 GPS 详情根页。
- 控制器详情只保留控制器连接、控制器类型、轮胎规格和传动比，不再显示仪表 UI、速度单位或速度来源。
- 仪表页的单位/来源/样式子视图使用独立导航状态；返回按钮、边缘返回、原生手势返回和快照刷新均回到仪表页。
- 当 `ESP_BMS_FEATURE_GPS=0` 时，宝马 S1000RR 仪表完全不调用或绘制卫星图标，也不因 GPS FIX 位变化触发该图标的重绘签名。
- GPS 编译启用时保持现有卫星图标及定位颜色行为。
- 不修改速度单位/来源的动作协议、NVS 格式、运行时选择策略或 Web UI。
- 更新 simulator-only 烟测和根目录 `preview/` 中受影响的横竖屏设置预览。

## Out Of Scope

- 手动“开始搜星”操作；接收机上电后继续自动搜星。
- GPS RMC、PPS、A-GNSS 和硬件引脚策略的语义调整。
- 新增仪表样式或修改宝马仪表的其他布局。

## Acceptance Criteria

- [ ] GPS+控制器构建显示独立的 GPS、仪表、控制器入口；三个详情页内容归属正确。
- [ ] 有效 GSA/GSV 更新可见数、参与定位数、最强 `C/N0` 和 `2D/3D`；损坏、截断及超时数据不会显示为当前有效搜星状态。
- [ ] 仅 GPS 构建显示 GPS 与仪表入口；仪表页有样式和单位，没有速度来源或控制器入口。
- [ ] 仅控制器构建显示仪表与控制器入口；宝马仪表不绘制 GPS 卫星图标。
- [ ] 无 GPS/无控制器构建不显示 GPS、仪表或控制器入口，且宝马仪表不绘制 GPS 卫星图标。
- [ ] 仪表子视图的按钮返回、边缘返回、原生手势返回和快照刷新均保持在仪表导航域。
- [ ] 横竖屏 headless 模拟器矩阵、主机自测和 ESP-IDF 构建通过；预览图位于根目录 `preview/`。
- [ ] 提交前 GitNexus `detect-changes` 只报告预期的 LVGL UI、模拟器和预览影响，或明确记录无法隔离的外部污染。
