# 技术设计：彦阳 BMS 协议适配与目录重组

## 边界与结构

保留 `esp_bms_bms_ble.c` 作为唯一的 NimBLE 生命周期所有者：扫描、连接、服务/特征
发现、CCCD 订阅、重连与向运行时投影数据均不下沉到品牌目录。新增一个小的内部纯 C
协议契约，放在 `components/esp_bms_bms_ble/protocols/`，用于提供：

- 品牌服务与特征 UUID；
- 订阅完成后的只读轮询帧；
- 通知字节流重组、长度/CRC 校验和已确认字段的规范化遥测输出。

现有帧解析移至 `protocols/ant/`，彦阳实现位于 `protocols/yanyang/`。只建这两个目录：
JK/JBD/Daly 当前没有协议代码，建立空目录会制造不真实的支持承诺。

组件通过现有 `bms_type` 枚举以显式 `switch` 选择品牌实现；不引入单实现工厂或配置
系统。解析器不包含 NimBLE、FreeRTOS、NVS 或 LVGL 头文件，使用固定容量状态对象和
规范化遥测结构返回结果。

## 彦阳传输契约

连接成功后按 APK 的特征 UUID 发现并订阅通知，写入固定 8 字节读命令：

```
[slave_addr, 0x03, start_hi, start_lo, count_hi, count_lo, crc_hi, crc_lo]
```

CRC 对前六字节计算，初值 `0xFFFF`，多项式为 Modbus 反射形式 `0xA001`；发送和接收
帧均以 CRC 高字节、低字节结束。响应形状为：

```
[slave_addr, 0x03, byte_count, payload..., crc_hi, crc_lo]
```

完整长度必须为 `byte_count + 5`。流重组器从任意通知分段中寻找合法帧，可连续提取多帧；
错误长度、错误函数、CRC 不符和超容量输入都丢弃并重新同步，绝不更新仪表快照。

只发送 APK 已证实的只读轮询序列：`0x003F/4`、`0x0001/47`、`0x0030/42`、`0x005A/22`。
首期向仪表投影 `0x0001` 主遥测；其他页仅做协议校验与轮询推进，直到存在已证实且仪表
需要的字段。不会发送设置、校准、升级命令。

## 数据契约

`0x0001` 响应的偏移以整个响应帧开头（包括地址、函数和长度）计。解析后写入既有
`esp_bms_dashboard_snapshot_t`，不改变显示层的量纲：

| APK 字段 | 编码/换算 | 快照字段 |
| --- | --- | --- |
| `SysVol` | 大端 U32，原始值 mV | `pack_voltage_mv` |
| `Current` | 大端 I16，原始值 0.01 A | `current_deci_amps = raw / 10` |
| `SocValue` | 大端 I16，原始值乘 0.4% | 百分比向最近整数截断 |
| `FactCap` | 大端 U16，原始值 0.1 Ah | `capacity_remaining_mah = raw * 100` |
| `RateCap` | 大端 U16，原始值 0.1 Ah | `total_capacity_mah = raw * 100` |
| `VolValue[]` | 大端 U16，单位 mV | 最高、最低、差值、平均值 |
| `TmpVol[]` | `T1=83`、`MOS=84`、`BAL=85`、`T2=86`，原始无符号字节减 40 摄氏度 | `T1->[0]`、`T2->[1]`、`BAL->[4]`、`MOS->[5]`；`T3/T4` 无效 |

电芯数与温度数先经过数组上限检查；不足完整字段、计数越界或零长度页均视为无效。
保护/告警位仅在 APK 位定义全部复核后投影；不把未知位臆造为告警名称。

## 设置与兼容性

新增 `ESP_BMS_IDF_BMS_TYPE_YANYANG` 和相邻的 LVGL 选择动作，保留既有枚举取值及
NVS 的 `bms_type` 键。运行时的策略校验、HTTP 配置/manifest 及静态 Web 兜底页面都接受
`"yanyang"`。TFT 使用可显示中文的现有设置字体显示“彦阳 BMS”；无中文字库的状态文本
保持 ASCII，例如 `BMS YY`。

用户选择新类型后沿用已有断开、清空遥测、重新扫描/连接流程。HTTP 及 Web 不接触协议
字段，只保存并显示品牌值。

## 验证与回滚

新增独立主机自测，使用 APK 推导的黄金请求及结构化响应，覆盖 CRC、拆分帧、粘连帧、
错误 CRC、错误长度、边界单体/温度计数和全部上表换算。模拟器验证新增设置项与动作到
快照的映射。随后运行现有自测与 ESP-IDF 构建；本次按用户要求不烧录。

协议实现、CMake 源文件清单和枚举/界面接入是可独立回滚的变更；回滚时移除彦阳条目及
目录即可，ANT 代码仍从其品牌目录构建。
