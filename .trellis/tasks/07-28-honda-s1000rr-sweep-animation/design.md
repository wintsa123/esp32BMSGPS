# 独立机车启动动画设计

## 配置契约

`esp_bms_dashboard_snapshot_t.boot_animation_style` 和 NVS `boot_anim`
独立于 `speed_dashboard_style`：

| 值 | 设置项 | 扫表主题 |
| --- | --- | --- |
| `0` | 电量充能 | 无 |
| `1` | BMW S1000RR | S1000RR |
| `2` | HONDA Fireblade | Fireblade |

值 `1` 保留旧版“机车扫表”的存储语义。只有编入 Fireblade 仪表时，值 `2` 才有效并可选；否则加载时使用现有安全回退。

## 启动时序

机车动画前 40% 为品牌开场：黑色覆盖层只显示居中的厂商图标，仪表保持隐藏。徽标使用横向缩放、倾斜和小幅平面旋转组合的 3D 翻转。BMW 在前 32% 显示蓝白圆盘标，32% 到 40% 切换为蓝色 `RR`；Honda 前 40% 始终显示红色翼标。之后覆盖层变透明，根据动画选择构造演示 snapshot，独立设置对应的仪表风格和速度，并在剩余区间完成 `0 -> max -> 0` 扫表。

- BMW：带环内 `BMW` 标记的蓝白圆盘标，随后显示蓝色 `RR`，再显示 S1000RR 能量条。
- Honda：红色翼标，随后显示 Fireblade 指针仪表。

覆盖层不创建状态或百分比标签。动画结束时复用现有 `boot_finish` 恢复实时 snapshot。

## 验证

模拟器以“当前仪表主题与动画主题相反”的组合启动，检查：品牌开场时仪表隐藏，扫表阶段仅目标仪表可见，速度与阶段一致，HUD 标签不存在。关键帧覆盖 BMW 图标翻转、Honda 翼标翻转和 Honda 峰值仪表。
