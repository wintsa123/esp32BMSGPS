# 补齐本田与 S1000RR 扫表动画

## Goal

让用户独立选择开机动画，并让机车扫表以所选厂商的品牌开场和对应仪表完成扫表。

## Background

- 用户希望开机机车扫表不再跟随当前仪表主题，而是在设备设置中直接选择。
- 用户明确要求机车扫表不显示底部状态文字；S1000RR 使用主仪表的速度能量条完成充能式扫表。
- Honda Fireblade 动画必须先显示并旋转红色厂商标识，再转入对应的仪表扫表。
- 现有启动 snapshot 已可携带独立的 `boot_animation_style`，并由 NVS 的 `boot_anim` 保存。

## Requirements

- R1: 用户可在“系统 -> 启动动画”独立选择“电量充能”“BMW S1000RR”“HONDA Fireblade”；该选择不受当前仪表主题影响，并使用现有 `boot_anim` NVS 键持久化。
- R2: 旧固件存储的机车扫表值 `1` 保持为 BMW S1000RR；Fireblade 未编入固件时不显示也不接受 Honda 选项。
- R3: BMW 与 Honda 扫表在开始阶段展示各自厂商图标并进行 3D 翻转，再显示对应仪表。BMW 使用带环内 `BMW` 标记的蓝白圆盘标，随后切换为蓝色 `RR`；Honda 使用红色翼标；之后两者均完成 `0 -> max -> 0` 扫表。
- R4: 机车扫表不显示底部 HUD、状态文案或启动百分比。S1000RR 仅用主仪表的能量条随演示速度充能并回落。
- R5: 扩展模拟器回归，验证动画主题与当前仪表主题相反时仍显示正确品牌，品牌开场会隐藏仪表且结束后切换到扫表。

## Acceptance Criteria

- [ ] 启动动画设置列出独立的 BMW 与 Honda 机车扫表选项，切换仪表主题不会改变已保存的启动动画选择。
- [ ] 选择 Honda 动画且当前仪表不是 Fireblade 时，启动先显示 3D 翻转的红色翼标，再显示 Fireblade 仪表和指针扫表。
- [ ] 选择 BMW 动画且当前仪表是 Fireblade 时，启动先显示 3D 翻转的 BMW 蓝白圆盘标，切换为蓝色 `RR`，再用 S1000RR 能量条完成扫表。
- [ ] 两种机车动画均没有底部 HUD、状态或百分比文字；扫表在品牌开场后完成 `0 -> max -> 0`。
- [ ] 模拟器回归、关键帧截图、适用的固件构建和 RFC2217 刷写尝试完成。

## Scope

- 调整启动动画设置、NVS 合法值策略、扫表绘制和对应模拟器回归检查。
- 不修改当前仪表主题的保存键、页面布局或正常运行时仪表显示。
