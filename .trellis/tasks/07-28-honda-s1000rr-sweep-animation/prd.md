# 补齐本田与 S1000RR 扫表动画

## Goal

补齐现有机车仪表主题的扫表反馈：本田主题有独立扫表动画，S1000RR 主题则以速度进度条表达扫表进度。

## Background

- 用户反馈本田主题当前缺少扫表动画。
- 用户明确要求 S1000RR 扫表时不显示 `READY`，改为显示随扫表速度变化的进度条。

## Requirements

- 本田主题进入扫表流程时必须绘制其扫表动画。
- S1000RR 扫表流程中必须以速度进度条反馈当前扫表进度，不得显示 `READY` 文案。
- 修改必须复用现有扫表的时序、绘制路径和主题选择机制，不能影响其他主题。

## Acceptance Criteria

- [ ] 选择本田主题时，扫表阶段可见且会随既有扫表流程变化的动画。
- [ ] 选择 S1000RR 主题时，扫表阶段显示的速度进度条随扫表数值变化，且不再出现 `READY`。
- [ ] 其他仪表主题的扫表行为不变。
- [ ] 通过项目适用的编译或最小验证命令。

## Scope

- 仅调整主题扫表的显示表现；不修改速度数据源、启动流程或主题配置界面。
