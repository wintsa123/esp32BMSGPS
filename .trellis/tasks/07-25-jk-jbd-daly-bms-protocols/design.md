# 设计

各品牌 parser 接收完整帧或可保存的流缓冲，输出 `esp_bms_bms_telemetry_t`。BLE 层仅负责按当前 `bms_type` 发现服务/特征、发出品牌轮询命令，并把通知字节交给 parser。这样协议代码可在主机 `assert` 自检中验证，NimBLE 生命周期仍只有一套。

| 品牌 | 服务与特征 | 请求/响应 |
| --- | --- | --- |
| JK | `FFE0` / `FFE1` | `55 AA EB 90` 请求，300 字节加和校验通知 |
| JBD | `FFF0` / `FFF1`、`FFF2` | `DD A5` 读请求，`DD 03` 响应，`FF AA` 可选认证响应 |
| Daly | `FFF0` / `FFF1`、`FFF2` | D2/P81 八字节 Modbus CRC16 请求与响应 |

连接后，服务发现根据品牌 UUID 完成；单特征协议把读写和通知句柄设为同一特征，双特征协议分别保存。JBD/JK/Daly 轮询按轮转请求，不改变现有重连、超时或遥测可用性策略。

解析器仅处理只读状态数据。校验失败、帧不完整或未知命令返回 false；调用端保留/重置缓冲但不写 runtime snapshot。Daly A5 没有该项目提供的可验证帧样本，因此保持显式未支持，避免把 D2/P81 误报为 A5。
