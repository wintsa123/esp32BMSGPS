# 480x320 BMS 页面信息精简

## Goal

精简 480x320 横屏 BMS 仪表盘的信息层级，使使用时长和告警状态更易扫读。

## Confirmed Facts

- 原生横屏 BMS 页面由 `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 的
  `create_native_bms_dashboard` 构建。
- 页面只在至少 480x320 的横屏显示器启用；本次不改变其他尺寸或页面。

## Requirements

1. 在电池 SOC 面板的使用时长右上方显示标题“使用天数”，并在标题下增加分割线。
2. 使用时长仅显示天、时、分，不显示秒。
3. 删除实时电气状态中的“当前电压”和“当前电流”标题，保留数值与单位。
4. 将告警与保护项目的状态图标垂直居中到圆形图标内。
5. “均衡状态”在待机时不能显示绿色勾；待机状态须使用非正常的中性状态图标。

## Acceptance Criteria

- [x] 480x320 横屏截图中，使用时长标题位于数值右上方，标题与数值之间有分割线，且数值没有秒字段。
- [x] 电压与电流数值上方不再出现“当前电压”或“当前电流”。
- [x] 所有告警与保护圆形图标中的勾均视觉居中。
- [x] “均衡状态”待机时不显示绿色勾。
- [x] 模拟器构建通过，并更新根目录 `preview/` 下的 480x320 BMS 截图。

## Out Of Scope

- 不更改 BMS 数据采集、状态位定义、其他分辨率布局或 Web UI。
