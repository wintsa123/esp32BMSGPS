# 黑色占位轮播设计

## Boundary

只修改 `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 内的页面切换过渡。
原有 `s_ui.pages`、手势判定、阈值、快照延迟和真实仪表对象保持不变。

## Object Model

`s_ui.pages` 同时拥有两组同坐标的轮播子页：

1. 既有 BMS、仪表、投屏真实页，默认可见。
2. 新增 BMS、仪表、投屏黑色标题占位页，默认隐藏；每页可吸附、不可点击，
   黑底和居中文字均由固定 LVGL 对象构成。

开始滚动时，显示占位页并隐藏真实页。占位页仍是 `s_ui.pages` 的子页，
因此 LVGL 保持原有横向可滚动边界和吸附目标。滚动期间标题随父容器自然移动，
不再维护屏幕浮层的手动 `x` 坐标。

## Event Contract

| Event / path | State change |
| --- | --- |
| `LV_EVENT_SCROLL_BEGIN` | 显示黑色占位页，隐藏真实页。 |
| `LV_EVENT_SCROLL` | 保持现有位移采样与阈值逻辑；过渡激活时跳过全屏仪表失效。 |
| `LV_EVENT_SCROLL_END`，仍需吸附 | 保持占位页可见，等待现有动画结束。 |
| 最终 `LV_EVENT_SCROLL_END` | 显示真实页并隐藏占位页，刷新延迟快照。 |
| `finish_page_scroll_state()` | 无条件恢复真实页并隐藏占位页。 |

占位页的 `x` 坐标由 `page_target_scroll_x()` 提供，故即使速度页不参与轮播，
投屏占位页仍与实际目标槽位一致。

## Trade-offs

- 不使用全屏浮层：浮层不能成为滚动内容，隐藏真实子页会收缩轮播的内容边界。
- 不使用截图、画布或额外帧缓冲：黑页只有背景和文本，满足拖动时最低绘制量。
- 不使用不透明度动画：黑页的跟手和原生吸附已经提供进入/退出动效，避免 TFT
  离屏图层及额外内存压力。

## Compatibility And Rollback

- 页面枚举、程序化目标页和滑动阈值不变。
- 若出现异常，回滚本任务提交即可恢复上一版屏幕浮层行为；不涉及配置、NVS 或
  迁移。
