# 修复黑场轮播占位页切换

## Goal

在 BMS、仪表和投屏的横向切页中，以实际可滚动的黑色标题页替代复杂
页面参与跟手移动。拖动期间只绘制黑底和居中页名，松手吸附后再显示
对应真实页面，以减少绘制压力且保持正常翻页。

## Confirmed Facts

- 主轮播是 `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 中的
  `s_ui.pages`；`page_scroll_event_cb()` 保留原有的拖动阈值、吸附和
  原生手势语义。
- 当前黑场实现把 `battery_page`、`gps_page` 和 `cast_page` 设为隐藏，
  因而它们不再贡献 LVGL 的可滚动内容边界。实机表现为能进入黑场但无法
  正确切到下一页。
- `settings_zh_16` 已包含 `仪`、`表`、`投`、`屏` 所需字形；不需要新增
  字库。
- 用户要求先完成模拟器行为验证，再安排下一轮实机烧录。

## Requirements

- R1: 每个物理轮播槽位都有同位置、同尺寸、可吸附的黑色标题占位页；
  占位页始终保持轮播的内容宽度和边界。
- R2: 拖动开始时隐藏真实复杂页、显示黑色占位页。标题随现有
  `s_ui.pages` 的滚动自然划出/划入，不再由屏幕浮层手动位移。
- R3: 松手后的阈值、取消、首尾边界、页面顺序、原生手势和
  `esp_bms_lvgl_ui_set_page(..., true)` 的最终目标页语义不变。
- R4: 吸附稳定后恢复对应真实页面、移除占位页，并刷新延迟快照；进入
  设置、锁屏、屏幕重建或任何提前收尾路径不得留下黑页或隐藏真实页。
- R5: 黑页进入和退出具有轻量、可感知的过渡，不引入位图缓存、额外帧
  缓冲、新依赖或高开销全屏重绘。

## Decision

- 黑页随原生轮播的拖动和吸附完成进入/退出；吸附完成的同一帧恢复真实
  页面。该方式保留可感知的黑页划动，且不增加延迟或透明度动画开销。

## Acceptance Criteria

- [x] AC1: 从任一可用页面慢拖到相邻页面时，黑底居中标题随手势完整
  划出/划入，且能够正常完成切页。
- [x] AC2: 低于既有阈值时返回原页；首尾拖动没有不存在的目标标题或
  空白页面；真实页在结束后恢复。
- [x] AC3: 原生手势、程序化切页和设置/锁屏收尾路径不改变最终页，也
  不遗留占位页。
- [x] AC4: 无头 LVGL 模拟器覆盖占位页的几何、标题、滚动边界、边界
  手势和真实页恢复，并通过全量功能矩阵。
- [x] AC5: `git diff --check`、目标 profile 构建和 GitNexus
  `detect_changes` 通过。

## Out Of Scope

- 修改原始手势输入、阈值、SPI/I80 时钟、LVGL 缓冲策略或仪表布局。
- 使用截图缓存、位图合成、额外帧缓冲或不透明度层动画来掩盖绘制开销。
