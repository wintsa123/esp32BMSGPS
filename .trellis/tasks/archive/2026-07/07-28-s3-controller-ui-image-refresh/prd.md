# S3 控制器 UI 480x320 图片重制

## Goal

将已确认的控制器仪表视觉同步到原生 LVGL，当前交付覆盖 ESP32-S3 的横屏 `480x320` 与竖屏 `320x480`，并保留可检查的预览图。

## Confirmed Facts

- 用户指定当前使用 `480x320` 横屏，且需要其旋转方向的 `320x480` 竖屏预览。
- 现有控制器仪表固件与渲染脚本仍以 `320x240` / `240x320` 为布局基准。
- 仓库已有 `preview/controller-native-portrait-320x480.png`，但没有对应的控制器 `480x320` 横屏预览。
- 新增或更新的 UI 预览图必须置于仓库根目录 `preview/`。
- 用户已确认新预览视觉，并要求同步修改原生 LVGL 控制器页面。

## Requirements

- 制作一张适合横屏 `480x320` 的控制器 UI 视觉稿。
- 制作一张适合竖屏 `320x480` 的控制器 UI 视觉稿。
- 视觉稿应延续现有控制器页的信息层级：速度、挡位、功率、转速、控制器温度和电机温度。
- 视觉稿沿用现有深色仪表底色、蓝色挡位面板和清晰的分区边框；横竖屏分别针对可用空间重排，不能只旋转或拉伸。
- 生成物须为可检查的位图预览，并保存到 `preview/`，不覆盖现有预览文件。
- 原生 LVGL 控制器页面在精确的 `480x320` 和 `320x480` 分辨率上采用对应的全页布局；保留已有的动态标签与快照更新路径。
- `320x240` 与 `240x320` 的既有控制器布局不得改变。
- 模拟器必须覆盖两种目标分辨率的控制器页对象创建和快照更新。

## Acceptance Criteria

- [x] 在 `preview/` 中新增一个尺寸精确为 `480x320` 的控制器 UI 图片。
- [x] 在 `preview/` 中新增一个尺寸精确为 `320x480` 的控制器 UI 图片。
- [x] 速度、挡位、功率、转速、控制器温度和电机温度均清晰可辨，且没有重叠或裁切。
- [x] 两个成品均针对各自方向的信息密度重新排版，而非将现有 `320x240` 或竖屏预览直接拉伸。
- [x] 原有预览图片保持不变。
- [x] `480x320` 的原生控制器页采用速度/挡位并列和底部四列遥测区，且所有动态标签可更新。
- [x] `320x480` 的原生控制器页采用上下主区和底部 2x2 遥测区，且所有动态标签可更新。
- [x] `320x240` 与 `240x320` 的控制器页保持原有对象创建和坐标分支。
- [x] 模拟器在 `480x320` 与 `320x480` 下通过控制器页对象与快照更新检查。

## Out Of Scope

- 其他屏幕分辨率、离线状态视觉变体和新增大号点阵字体。
