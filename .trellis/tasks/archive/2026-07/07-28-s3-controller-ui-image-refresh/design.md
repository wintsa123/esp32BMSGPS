# Design

## Boundary

仅修改 `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 的控制器页静态布局和模拟器断言。现有 `set_controller_dashboard()` 继续负责动态遥测文本，不改变数据、BLE 或页面映射。

## Layout

- `480x320`：外框内左侧速度、右侧蓝色挡位面板，底部一行四列功率、转速、控制器温度和电机温度。
- `320x480`：外框内上方速度、中部蓝色挡位面板，底部 2x2 遥测区。
- 仅精确匹配这两种 S3 画布；`320x240` 和 `240x320` 继续使用原始分支。
- 所有动态对象继续赋给既有 `s_ui.controller_*` 字段，静态标题和单位不进入快照更新路径。

## Validation

扩展模拟器控制器页 smoke check 至两种原生画布，确认全部动态标签已创建；用模拟器分别运行 `480x320`、`320x480` 并生成预览截图。
