# 优化控制器与本田火刃竖屏仪表尺寸

## Goal

让控制器仪表和本田火刃仪表在 320x480 竖屏中充分、清晰地使用可用画布，避免固定 240x320
坐标造成的右侧和下方留白。

## Confirmed Facts

- 控制器仪表由 `create_controller_dashboard()` 创建；当前竖屏统计区固定在
  `y=236, h=72`，而 320x480 页面高度为 480，导致下半区留白。
- 火刃仪表由 `fireblade_create_portrait()` 创建；当前坐标系固定为 240x320，320x480
  模拟器预览显示内容仅覆盖左上区域。
- 用户要求不使用缩放函数。现有横屏火刃的用户本地改动不属于本任务，不能回退或混入。

## Requirements

- R1：为精确 320x480 的控制器仪表建立原生竖屏几何，使速度、档位和四项状态信息覆盖
  主画布，不留大块无内容区域。
- R2：为精确 320x480 的火刃仪表建立原生竖屏几何，使顶部状态、仪表盘、速度和四项辅助
  指标完整使用主画布。
- R3：原生竖屏分支不得调用 `lv_obj_set_style_transform_scale` 或任何等价缩放 API；通过
  直接位置、尺寸和字号完成排版。
- R4：240x320 火刃竖屏同步优化日期时间、温度单行、档位层级和指针边框；480x320 横屏
  保持既有布局，三种分辨率继续由既有数据快照更新。

## Acceptance Criteria

- [x] AC1：320x480 控制器预览中，所有面板位于屏幕边界内，统计区延展至下方，且无超过
  96px 的无内容底部区域。
- [x] AC2：320x480 火刃预览中，仪表元素位于屏幕边界内，覆盖完整竖屏构图，不再以
  240x320 左上角小画布显示。
- [x] AC3：本任务新增或修改的竖屏函数不含缩放 API 调用。
- [x] AC4：模拟器构建成功，320x480、240x320 与 480x320 headless 回归通过。
- [x] AC5：生成并目视核对根目录 `preview/` 中的两张 320x480 预览图。
- [x] AC6：240x320 与 320x480 顶栏均显示小字号 `YY-MM-DD` 和 `HH:MM`；320x480
  剩余里程数值居中，`km` 单位与其底部齐平。

## Out Of Scope

- 修改 BMS 竖屏布局。
- 修改现有火刃横屏布局或其中的用户本地改动。
- 调整与本任务无关的 BMS 或横屏视觉设计。
