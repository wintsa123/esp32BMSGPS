# 设计：控制器与火刃 320x480 竖屏布局

## 边界

仅修改 `components/esp_bms_lvgl_ui/esp_bms_lvgl_ui.c` 的控制器和火刃创建路径。快照更新函数
继续写入既有 `s_ui.controller_*` 与 `s_ui.fireblade_*` 标签，不改变数据结构或协议。

## 布局策略

- `create_controller_dashboard()` 使用精确 `320x480` 判断，为速度、档位和统计区设置独立
  像素几何；240x320 保持原数值。统计区使用完整剩余高度，并随其行高定位文本。
- 新增火刃原生竖屏创建函数，直接在 320x480 页面创建顶部状态栏、圆形刻度、指针、档位、
  速度和底部指标；320x480 与 240x320 状态栏左侧均显示分开的日期与时间，日期使用较小字号，
  右下指标以单行显示控制器与电机温度。320x480 剩余里程数值居中，`km` 单位与数值底部齐平。
  速度单位与主速度数字右边缘对齐；240x320 档位圈显式置于指针上层，并收窄指针外轮廓。
  刻度、指针和文字均使用目标像素坐标及现有绘制辅助函数。
- `create_fireblade_dashboard()` 只在精确 320x480 时调用新分支；其余尺寸继续走当前
  `dashboard_viewport()` 回退路径。

## 禁止与兼容

- 不在新分支中使用 `lv_obj_set_style_transform_scale`、变换缩放或缩放动画。
- 不触及现有横屏火刃函数及其用户本地变更。
- 通过现有模拟器快照刷新标签和指针；删除或替换控件时必须保持 `s_ui` 指针赋值完整。

## 回滚

移除两个精确 320x480 条件分支即可恢复当前回退布局；不影响其他分辨率。
