# GT1151Q 原生手势与校准策略设计

## 边界

变更只覆盖 GT1151Q/S3 的输入采集、显示服务转交和 LVGL UI。保留第三方
`esp_lcd_touch_gt1151`、I2C 100 kHz、`0x814E` 缓冲区就绪位兼容修复、其他触控 profile 的
校准流程和所有坐标控件。

## 数据流与契约

```
GT1151Q 0x814C raw byte
  -> bridge decode and de-duplicate
  -> one pending semantic gesture
  -> display service after lv_timer_handler()
  -> UI gesture dispatcher
  -> existing page, quick-panel, settings, or focus behavior
```

| 边界 | 输入 | 输出 | 责任 |
| --- | --- | --- | --- |
| GT1151Q -> bridge | `0x814C` 原始字节 | 受限语义手势枚举或空值 | bridge 只在 GT1151 profile 读取、校验和去重 |
| bridge -> display service | 单个待消费语义手势 | 无或一个 UI 调用 | service 在现有 LVGL 任务和锁内消费 |
| display service -> UI | 已验证语义手势 | 已有 UI 行为或诊断日志 | UI 决定页面/面板/焦点状态，不读取 I2C |

bridge 使用一个明确的语义枚举，不把 GT1151Q 原始寄存器值泄漏给 UI：

| 原始值 | 语义 |
| --- | --- |
| `0xAA` / `0xBB` | 右滑 / 左滑 |
| `0xAB` / `0xBA` | 下滑 / 上滑 |
| `0xCC` | 双击，仅诊断 |
| `0xC1` / `0xC2` / `0xC4` / `0xC8` | 上一项 / 下一项 / 确认 / 返回取消 |

ASCII、`0x01..0x0A` 自定义码和其他未知值不产生 UI 动作，仅限频记录原始值。相同非零值只在
控制器先恢复为零后才可再次派发，防止一个锁存手势重复触发。

## GT1151Q 读取与确认

桥接层在调用第三方 `esp_lcd_touch_read_data()` 前读取 `0x814C`，再让原有驱动照常读取并写零
确认 `0x814E`。不写 `0x814C`，不改第三方驱动。首次实机日志记录手势、状态和派发次数；若
控制器在 `0x814E` 确认后不恢复手势值，再以数据手册和日志为依据决定是否需要最小确认写入。

## 坐标与手势互斥

GT1151Q 启用原生手势后：

- 仪表主轮播关闭 LVGL 的横向坐标翻页，左/右原生手势成为唯一翻页来源。
- 原生下滑打开快捷面板、上滑仅关闭已打开的快捷面板；与之竞争的首页坐标拉取区不处理该
  profile 的全局开关手势。
- 设置页的纵向滚动、边缘返回、滑条和普通控件仍使用坐标触摸。
- 双击只输出诊断日志，不占用或改变业务状态。

这让同一次滑动不会同时走 `page_scroll_event_cb()` 和原生导航。若实机发现 `0x814C` 只在松手
后可读，前述禁用竞争坐标路径仍可防止重复导航。

## 按键焦点

UI 在设置页和快捷面板维护一个固定容量、仅包含当前可激活控件的焦点列表。每次创建、清空或
切换相关视图时重建列表；焦点以现有 LVGL 状态和可见轮廓标记，并自动滚动到可见区域。

- `0xC1` / `0xC2` 在当前范围内循环到上一项 / 下一项。
- `0xC4` 向焦点对象发送现有 `LV_EVENT_CLICKED`，复用原有回调。
- `0xC8` 优先关闭当前弹层或快捷面板，否则调用已有设置返回路径。

焦点候选在现有设置行、下拉选项和快捷面板按钮创建处注册，不按像素坐标或固定行号猜测。
坐标点击与按键焦点共用同一回调，所以不会复制设置业务逻辑。

## 校准能力

显示服务把两个明确能力传给 UI 初始化：GT1151Q 不支持人工校准、且支持原生全局手势。UI 过滤
“屏幕校准”行并拒绝任何残留入口；bridge 对 GT1151Q 跳过加载、应用、保存和清除校准 NVS。
其他 profile 保持现有校准 API 和 UI。模拟器显式提供能力值，避免把 S3 行为隐含为默认行为。

## 验证与回滚

- 模拟器直接调用语义手势 UI 入口，验证页面切换、快捷面板开关、双击无副作用、四键焦点和
  GT1151Q 隐藏校准项。
- S3 profile 构建后，经 RFC2217 日志验证 `0x814C` 时机、单次派发、`0x814E` 按住兼容、坐标
  控件和无 panic/WDT。
- 回滚本任务的 bridge、display service、UI 和模拟器差异即可恢复坐标手势与校准；不会改动
  NVS 内容或第三方组件。
