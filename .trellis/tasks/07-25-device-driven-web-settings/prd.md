# 设备驱动的 Web 设置

## Goal

让单片机在 Web 客户端连接后提供当前固件支持且允许编辑的设置能力清单。局域网页面和 Vercel 页面只按该清单渲染并调用设备现有设置行为，定制或裁剪固件不会显示不支持的功能。

## Background

- 本地 Web 位于 `main/web/index.html`，Vercel React 应用位于 `vercel/src/App.tsx`。两者目前各自硬编码设置字段。
- Vercel 由浏览器直接请求用户输入的局域网设备地址；设备已有跨域和 Private Network Access 响应头，不存在云端中继。
- 设备的现有 `POST /api/config` 经运行时主循环写入并持久化。BMS 与 OTA 也已有独立执行路由；新功能必须复用这些行为。
- 编译期 feature 宏决定 network、BMS、GPS、controller、OTA 等模块是否存在，当前 Web 页面未据此裁剪。

## Requirements

- [ ] 设备提供版本化、可验证的运行时能力清单，表达项目标识、双语显示信息、受限控件类型、当前值、选项或取值约束、是否可编辑及其既有提交入口。
- [ ] 设备仅声明实际支持且允许 Web 修改的功能；缺失模块、不可编辑项和未知项不得以可操作控件呈现。
- [ ] 局域网 Web 和 Vercel Web 在每次 HTTP 连接成功后清空旧状态、获取清单并以同一契约渲染；页面不得保留独立的固定设置功能表。
- [ ] 普通设置提交继续走现有 `/api/config` 的校验、主循环交接和 NVS 写入；BMS 扫描/绑定与 OTA 继续走各自现有处理路径，不新增浏览器或 Vercel 侧设置持久化。
- [ ] 清单覆盖除蓝牙分享/控制连接和热点密码以外的全部现有 Web 设置功能，包括普通值、BMS 扫描/绑定和 OTA；每项只在设备声明支持时出现。
- [ ] 未连接、旧固件、协议版本不匹配、清单无效或操作失败时，页面必须清除可编辑状态并在既有消息组件显示明确错误。旧固件固定提示“固件不支持动态设置，请升级”。
- [ ] 新增 Web 文案先提供中文；英文由设备设置中的语言项切换。TFT 的既有 ASCII 语言状态限制不变。

## Acceptance Criteria

- [ ] 对至少两套功能不同的固件清单，两个 Web 页面仅显示设备宣布的可编辑项，且没有被裁剪模块的控件。
- [ ] 两个页面对相同设备修改普通设置时，都到达相同的既有设备写入路径；重新读取清单后正确显示设备返回的当前值。
- [ ] BMS 扫描/绑定和 OTA 仅在设备分别声明能力时显示；禁用 BMS 或 OTA 的固件没有对应的可调用控件。
- [ ] 切换设备地址、断连、清单错误或设置被拒绝时，页面不保留另一设备的表单值或可提交状态。
- [ ] 旧固件没有能力端点时，两个页面仅在原有消息组件显示升级提示，且不渲染旧的固定设置表单。

## Decisions

- 不为旧固件保留固定设置页。
- 不动态化热点密码和蓝牙分享/控制连接。
