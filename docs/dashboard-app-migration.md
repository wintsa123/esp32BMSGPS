# 两轮智控 App 功能迁入核对

对照旧版提交 `22cd1e33`（2026-10-26）和本次迁入后的界面。底栏为爱车、功能、我的；功能页按用户要求保持空白。

“我的”主页只保留蓝牙连接、Wi-Fi 连接、系统信息三张列表卡。设备设置、固件更新、行驶历史收进系统信息弹层。语言切换仍在设备设置；面板版本读取实际 `/api/status.version`，App 版本通过 `BmsNative.getAppInfo()` 读取安装包，不使用网页工程版本替代。

| 旧版能力 | 当前入口与迁入情况 |
| --- | --- |
| 蓝牙与热点 API 连接 | 首页快捷入口及我的连接卡，沿用设备 API / BLE 协议 |
| 控制器挡位、转速、功率及温度 | 系统信息展示实际状态；App 中设备工具可进入完整原生仪表 |
| 历史会话、曲线和故障日志 | 首页最近骑行箭头、系统信息的行驶历史；网页已支持真实电压/电流/SOC 曲线、故障分页、重试和跨会话隔离 |
| 骑行峰值 | 行驶历史中的峰值快照，沿用真实设备数据 |
| GPS 轨迹 | 设备设置的 manifest 地图项；App 系统信息的原生记录与轨迹入口 |
| 投屏与反向控制 | App 首页投屏及系统信息投屏入口，保留原生实现 |
| 显示、语言、速度来源、设备类型等 | 系统信息的设备设置，沿用 manifest 与原生设置 |
| 固件更新 | 系统信息的更新弹层，保留在线列表、本地 bin、四位验证码；原生设置保留完整进度流程 |
| App 更新及安装 | App 系统信息的 App 更新入口，使用旧版原生更新实现 |

旧版 `MainActivity` 仍提供原生工具页。部分旧 BMS 详情字段存在未初始化的不可达代码，未认定为迁移前已经展示的功能；基线没有发现轨迹动画回放或 CSV 导出实现。

验证包括真实浏览器的界面与模拟设备接口回归、真实配色引擎比对、历史分页及迟到响应测试、Android 单元测试。未将模拟接口测试等同于实车、真机 BLE 或 OTA 验收。

首页车辆图片进入独立编辑页，支持选择本机图片、拖拽、缩放和 3:2 裁剪；预置默认 AE5 及四款原创中性车辆插图。选择和恢复默认先修改草稿，只有确定才写入本机存储，取消、坏图或保存失败不会覆盖原图。网页和 App 共用该页面，预置素材随包离线提供。
